CCCC is a local-first multi-agent collaboration kernel for coding agents. It provides a daemon-centered control plane with append-only ledger persistence, role-based routing, inbox/read/ack semantics, task and coordination state, automation (nudge/idle/keepalive), web/CLI/MCP/IM ports, and multi-runtime actor support. Main package lives under src/cccc with daemon, kernel, ports, runners, cli, and providers modules. Runtime state is stored under CCCC_HOME rather than the attached repo.
